# 🌱 Habit Heatmap

A simple habit tracker that helps you track your daily habits using a GitHub-style green heatmap calendar.

## ✨ Features

- Add multiple habits
- Mark habits as completed for each day
- GitHub-style green heatmap
- Monthly calendar navigation
- Today button
- Completion statistics
- Data saved using Local Storage
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## 📌 How It Works

Click on any date and select the habits you completed that day.

The green intensity changes based on how many habits you completed:

- 0 habits → Very Light
- 1 habit → Light Green
- 2 habits → Medium Green
- 3 habits → Dark Green
- 4+ habits → Darkest Green

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Add your habits and start tracking your progress!
